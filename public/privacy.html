피부일지 개인정보처리방침

시행일: 2026년 11월 7일

피부일지(이하 "앱")는 개인이 자신의 피부 상태와 스킨케어 루틴을 기록하기 위해 만든 웹앱입니다. 앱 운영자는 별도의 서버를 두지 않으며, 사용자의 데이터를 수집하거나 보관하지 않습니다.

1. 저장하는 정보

사용자가 직접 입력한 사진(얼굴·등·가슴), 스킨케어·클렌징 제품 사용 기록, 운동 기록, 뾰루지 위치·상태·처치 기록, 메모가 저장됩니다.

2. 저장 위치

  • 모든 데이터는 사용자 본인의 구글 드라이브 안 "피부일지" 폴더에 파일로 저장됩니다.
  • 업로드 전 잠시 보관하거나 빠르게 보여주기 위해 사용자의 브라우저(IndexedDB, localStorage)에 사본이 저장될 수 있습니다.
  • 앱 운영자나 제3자의 서버로 전송되는 데이터는 없습니다.

3. 구글 계정 권한

앱은 구글 OAuth를 통해 https://www.googleapis.com/auth/drive.file 권한만 요청합니다. 이 권한으로는 앱이 직접 만든 파일에만 접근할 수 있으며, 드라이브의 다른 파일은 보거나 수정할 수 없습니다. 구글 API에서 받은 정보는 기록 저장·표시 목적으로만 사용하며, 다른 용도로 사용하거나 제3자에게 제공·판매하지 않습니다.

앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 삭제

  • 구글 드라이브에서 "피부일지" 폴더를 삭제하면 모든 기록이 삭제됩니다.
  • 앱의 접근 권한은 구글 계정 → 서드파티 앱 및 서비스에서 언제든 해제할 수 있습니다.
  • 브라우저에 남은 사본은 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

5. 문의

이 앱은 개인용으로 운영됩니다. 문의는 구글 OAuth 동의 화면에 표시된 지원 이메일로 해주세요.
